Importa

Carica un file Excel (anche scaricato da Google Fogli). Ogni foglio chiamato come un mese, per esempio "Maggio 2026", va nel mese corrispondente.

I mesi importati sostituiscono i valori già presenti in quei mesi. Le voci vengono abbinate per nome; quelle nuove si aggiungono in fondo.

Elimina

Cancella i valori inseriti. Non si può annullare: esporta prima un file se vuoi tenerne una copia.

Esporta

Scegli i mesi: ogni mese diventa un foglio del file Excel, che si apre anche con Google Fogli.
